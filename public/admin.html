⚡ How to Send OTP from your other projects (Node.js / Fetch):

fetch('https://otp-system-qy3i.onrender.com/api/v1/send-otp', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'YOUR_API_KEY'
  },
  body: JSON.stringify({
    identifier: 'user@example.com', // or '9926888306'
    channel: 'email'                 // 'email' | 'whatsapp' | 'telegram'
  })
});

✅ How to Verify OTP from your other projects:

fetch('https://otp-system-qy3i.onrender.com/api/v1/verify-otp', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'YOUR_API_KEY'
  },
  body: JSON.stringify({
    identifier: 'user@example.com',
    otp: '123456'
  })
});
